# 隐私说明（草案）

这是面向 BLCUhelper 校园信息聚合场景的隐私说明草案。本站为学生自建的非官方校园信息整理与聚合工具，非北京语言大学官方平台。本说明属于公开上线前需由维护者进一步确认的草案，不作为已批准的正式法律声明。

| 项 | 值 |
|---|---|
| 版本 | v0.1.0-draft |
| 生效日期 | 2026-10-21 |
| 运营主体 | BLCUhelper 维护团队（学生自建非官方项目，非北京语言大学官方机构） |
| 联系方式 | 站点站内反馈页（/feedback） |

页首说明：

> 使用 BLCUhelper 不需要注册或登录，不收集、不索取校内统一身份认证账号及密码。我们只处理保障系统基础运行与处理必要反馈所需的信息。

## 1. 免登录与官方认证隔离

本站所有公开功能（网页浏览、分类筛选、搜索、公开 RSS 订阅、公开 API 与 MCP 接口）完全匿名提供，不设普通学生注册与登录通道。

本站**绝不**接入校内统一身份认证登录态，**绝不**索取、收集或存储任何学生的学号、数字北语密码或登录凭据（Cookie/Token）。如遇任何自称本站并索取校园网账号密码的情形，请勿提供并立即通过站内反馈页（`/feedback`）举报。

校内官方平台请直接访问数字北语服务大厅：[https://ehall.blcu.edu.cn/index.html](https://ehall.blcu.edu.cn/index.html)。

## 2. 浏览器本地数据与搜索请求

为提升浏览体验，以下偏好与记录仅保存在你的浏览器本地存储（Local Storage）中：

- 收藏记录、已读标记；
- 深浅色外观设置；
- 最近搜索词列表（仅在本地暂存最近 10 条以便再次点击）；
- 更新日志的已读版本号；
- 反馈表单的未提交草稿。

返回列表时的滚动位置与展开状态仅保存在当前标签页的会话存储（Session Storage）中，关闭标签页即自动销毁。上述本地偏好和历史记录本身不会作为用户画像整份同步至服务器；但在你主动发起搜索时，输入的搜索关键词及筛选参数为提供检索结果会作为请求参数发送至后端接口，并可能出现在服务端处理与访问日志中。清除浏览器缓存或更换设备后本地数据将重置。收藏与已读记录可在“收藏”页通过纯文本/JSON 自行导出与导入。
## 3. 站内反馈处理

当你在反馈页（`/feedback`）主动提交内容时，系统会记录：

- 你填写的反馈说明与建议；
- 你自愿选填的联系邮箱（若未填写则不记录）；
- 提交时所在页面的访问路径以及你主动选择附加的截图；
- 为防止恶意刷量与自动化滥用，系统会基于请求网络环境与客户端特征计算出单向不可逆的防护标识，用于速率限制与滥用封禁。

反馈内容仅用于排查信息准确性、修复系统问题或答复你的咨询，不用于任何商业化分析或出售给任何第三方。

## 4. 管理员后台认证

系统后台仅供经过授权的维护者进行来源管理与系统运维。后台登录采用密码凭据与安全 Session Cookie，仅对已明确分配管理员权限的人员生效，不对普通访问者开放。

## 5. 服务器与网络访问日志

本站默认不加载任何第三方商业用户行为统计 SDK。部署服务器（如 Fastify 运行时）、反向代理或 CDN 会依据常规运维与网络安全要求记录访问日志，可能包含请求 IP 地址、访问时间、请求 URL（含检索参数）、HTTP 状态码及客户端 User-Agent，具体以实际部署环境的保留策略为准，不承诺已作匿名化脱敏。该日志主要用于网络故障诊断、异常排查与接口限流防护。
## 6. 第三方链接与外部跳转

本站条目均附带信息原始发布的官方网页或公众号链接。当你点击这些链接离开本站时，将直接访问对应第三方网站或服务平台，适用该第三方自身的隐私规范与用户协议。

## 7. 联系与删除请求

如需对通过反馈页提交的记录提出查询、更正或删除请求，请通过本站站内既有反馈渠道（`/feedback`）与维护团队取得联系。
