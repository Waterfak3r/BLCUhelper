# 使用规则（草案）

这是面向 BLCUhelper 校园信息聚合场景的使用规则草案。本站为学生自建的非官方校园信息整理与聚合工具，非北京语言大学官方平台。本规则属于公开上线前需由维护者进一步确认的草案，不作为已批准的正式法律声明。

页首说明：

> BLCUhelper 是学生自建的非官方校园信息整理与聚合工具。本站仅提供公开信息摘要与原文链接，所有原文版权均归原发布机构或作者所有。

## 1. 站点性质与官方平台入口

BLCUhelper 并非北京语言大学官方平台，亦不代表任何校内官方机构。本站设立目的是方便学生查阅散落在各处的公开通知，减少无关信息干扰和重要事项漏读。

校内官方统一业务与认证系统请访问数字北语官方服务大厅：[https://ehall.blcu.edu.cn/index.html](https://ehall.blcu.edu.cn/index.html)。本站不接入、不要求、亦不存储任何学生的校内账号、统一身份认证密码或登录凭据（Cookie/Token）。凡涉及个人学籍、私密信息、成绩查询或正式校务办理，请务必直接通过官方系统处理。

## 2. 内容来源、覆盖范围与展示方式

本站内容来自公开校园网官网栏目（自动采集）以及管理员核验后的公众号推文（半自动导入）：

- **覆盖限制**：本站仅覆盖部分已接入的公开栏目与经核验的文章线索，**不保证**涵盖全校所有部门、学院或公众号的全部通知。数字北语等需要登录的内网通知本站一律不接入。
- **列表说明**：页面上的“全部动态”（`/all`）并非“抓取到的所有原始消息”，未通过基本预筛、无可信发布日期或缺失可用正文的条目不会在公开列表呈现；后台仅作为数据排查入口。
- **日报定位**：日报是经过规则筛选的重点精选摘要，并非全校通知的完整清单，读者不能假定“只看日报就不会遗漏任何事项”。
- **摘要与版权**：除来源方明确授权转载的情形外，本站全文展示许可默认关闭（`site_fulltext=false`、`syndicate_fulltext=false`），仅向读者展示提取的简短摘要、基本要素与原始链接。重要事项、具体办理流程、附件下载及最终要求务必以原文为准。

## 3. 来源方的更正、删除与下架

若相关部门、机构或作者对本站收录的摘要、链接或展示方式有异议，或要求更正、删除、下架相关内容，请通过本站既有的站内反馈页（`/feedback`）提交请求。维护团队核实后会尽快处理并下架对应条目。

## 4. 接口与使用规范

本站提供的公开 RSS、只读 API 与 MCP 接口均为匿名只读服务：

- 仅供个人查阅、校园生活辅助与合理学术研究用途；不得用于商业营利、恶意高频爬取或干扰站点正常运行的行为。
- 请求时请遵守各接口响应中的 `Cache-Control` 缓存时间及限流规则，遇到 429 状态码请严格等待 `Retry-After` 指定时长，禁止高并发重试。

## 5. 免责声明

本站各项信息均按“现状”提供，不提供任何明示或暗示的法律保证。通知日程、资格条件、办理要求等均可能因校方安排变动而调整，请使用者在采取实质行动前通过官方渠道进行核实。因依赖本站摘要信息产生的一切延误或损失，本站及维护者不承担法律责任。
